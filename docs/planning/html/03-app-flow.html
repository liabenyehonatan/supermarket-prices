IN ONE MINUTE
  • Six screens: Home, Product, Scan, Basket, Deals, About, each with its own plain address. A floating bottom bar has Home, Scan (raised) and Basket.
  • The usual path: search → product → add to basket → compare the basket. Deals is a second way in.
  • Nothing dead-ends: every failure shows a plain message.

03 What happens on a tap, and when it goes wrong

The tapWhat happensIf it goes wrong
SearchResults appear and keep loading as the user scrolls; sort by relevance or cheapest.“No products found”, or “Could not load, try again”
+ add to basketThe item flies to the basket icon and joins the active basket (the first add of a visit asks which, if there are several).Adding the same item raises its quantity
Filter or Near meThe list narrows and the choice is remembered; “near me” shows stores within 15 km with distances.None match or no permission: all stores shown, with a note
Deals pageA search box finds deals by product or chain; the list keeps loading as the user scrolls, deals with a picture first.No match: a message and a button to clear the search
Deal cardOpens the product; the button adds exactly the units the deal needs; a group deal opens a list to choose from.A finished deal is simply not listed
Compare basketTotals at each store with deals applied and shown per line.Empty basket message; “N items missing”; a note when we lack fresh deal data for a branch
ScanThe camera reads the code and the product opens.Clear message with no permission or camera; unknown code offers typing
Back from a productSame results or same card, same scroll position.If cleared from memory, the list loads again

Failures never leave a blank screen: an unexpected error shows “Something went wrong” and a way home, a late answer never overwrites a newer one, pages fade in without flashing, and blocked browser storage only means the basket is not kept.

04 The journey nobody sees: the twice-daily refresh

At 06:00 and 18:00 Israel time; each run takes 2 to 3 hours.

Startone run at a time
→
Downloadchain by chain, with time limits
→
Checka cut-off file is rejected
→
Saveprices, then promotions
→
Tidy updelete the file; refresh the pre-worked tables
Golden rule. A file counts as loaded only once its data is safely saved, and is deleted only after that. A chain that fails is recorded and the others carry on; a failed run retries two hours later.
