IN ONE MINUTE
  • A Worker collects prices twice a day; a website and API show them. They meet in one database.
  • Everything runs on one server in Israel, because 12 chains only answer Israeli addresses.
  • The public side can only read the database, so it cannot change prices.

02 What it is built with

PartToolIn plain words
WebsiteReact, TypeScript, ViteFast single-page site in Hebrew, right to left. Barcodes are read in the browser (ZXing).
APIPython 3.12, FastAPI14 endpoints: search, compare, basket, deals, cities, chains, pictures and more.
DatabasePostgreSQL 16, pg_trgmOpen-source database; the add-on makes Hebrew search forgive spelling mistakes.
Price collectionOpen-source scraper and parserCommunity libraries that download and read every chain’s files, pinned to a tested version.
Running itDocker Compose, Caddy, nginxEvery part in its own box. Caddy gives sali.one its HTTPS certificate; nginx caches answers, limits 20 requests a second per visitor and adds security headers.
Search visibilityServer-built page headersThe server gives each page its own title, description and structured data, real 404s, and a sitemap that lists every priced product.
Quality and releaseAbout 270 tests, GitHub ActionsEvery change is tested against a temporary database; once it passes on main it is deployed to the server automatically.

04 Safety and decisions already made

TopicWhat was decided, and why
Read-only public sideThe API connects as a database user that can only read (and set a picture link). A flaw in the site cannot change prices.
LimitsRate limits, caps on search length and basket size (100 items), and security headers.
One server in IsraelInstead of managed cloud services: size limits, network delay, and Israeli-only chains.
Load 500 rows at a timeOne row at a time took 30 s where batches take 3.4 s for the same files.
Full price files onlyA full file corrects itself; a changes-only file can miss something.
MonitoringA health address fails if data is older than 36 hours, or a single chain is silent for 5 days, and an alert is sent.
